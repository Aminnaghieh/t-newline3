# Liara SRE Super Agent — نسخه وب 🚀

سوپر ایجنت هوشمند مدیریت و عیب‌یابی ابر لیارا، با **محیط گرافیکی اختصاصی وب** و تم کامل سایت liara.ir
(تم دارک `#242a27`، گرادیان امضا `#87fcc4 → #28c1f5`، فونت Vazirmatn، چیدمان کامل RTL فارسی).

این پروژه نسخه‌ی تکامل‌یافته‌ی ایجنت CLI پایتونی است؛ تمام منطق هسته (پلنر، RCA، مانیتور، دیباگر، دیپلویر) به TypeScript پورت شده و روی Next.js 16 اجرا می‌شود.

---

| 🔍 ممیزی کامل | ثبت همه‌ی عملیات با سطح ریسک، منبع و جزئیات |
| 🎭 حالت دمو | به‌طور پیش‌فرض با ۵ پروژه‌ی شبیه‌سازی‌شده اجرا می‌شود؛ بدون نیاز به حساب واقعی |

## 🧰 پیش‌نیازها

- **Bun 1.x** (پیشنهادی) یا **Node.js 20+**
- هیچ سرویس خارجی لازم نیست — دیتابیس SQLite فایل است و حالت دمو آفلاین کار می‌کند.

## ⚡ اجرای سریع

```bash
# ۱) نصب وابستگی‌ها
bun install        # یا: npm install

# ۲) ساخت دیتابیس (اگر db/custom.db موجود نیست)
npx prisma db push

# ۳) اجرای محیط توسعه
bun run dev        # → http://localhost:3000
```

## 🏗️ بیلد پروداکشن

```bash
bun run build
bun run start      # اجرای سرور standalone روی پورت 3000
```

## 🔑 اتصال به حساب واقعی لیارا

1. از پنل [liara.ir](https://liara.ir) یک **API Token** بسازید (`تنظیمات ← API Token`).
2. در وب‌اپ به صفحه **تنظیمات** بروید و توکن را وارد کنید.
3. حالت اتصال زنده به `api.liara.ir` فعال می‌شود؛ دکمه «تست اتصال» صحت توکن را بررسی می‌کند.

> توکن فقط در دیتابیس محلی شما ذخیره می‌شود و در لاگ‌ها به‌صورت خودکار mask می‌گردد.

## 📁 ساختار پروژه

```
src/
├── app/
│   ├── page.tsx              # اپ تک‌صفحه‌ای (تم لیارا، RTL)
│   └── api/                  # agent (SSE)، projects، deploy، audit، settings…
├── components/liara/         # shell، dashboard، chat، projects، deploy-wizard، audit، settings
└── lib/liara/
    ├── agent/                # engine (روتر LLM + SSE)، tools (۹ ابزار + دروازه HITL)، prompts
    ├── planner.ts / plans.ts # ماتریس پیشنهاد پلن + کاتالوگ قیمت لیارا
    ├── rca.ts                # موتور تحلیل علت ریشه‌ای + AlertEngine
    ├── client.ts             # کلاینت API لیارا (retry، rate-limit، fallback دمو)
    └── store.ts              # تنظیمات، ممیزی و تاریخچه چت در Prisma
```

## 🔐 امنیت

- عملیات تغییر حالت (resize/restart/deploy/plan change) فقط با **تأیید صریح کاربر** و امضای SHA-256 اجرا می‌شوند.
- هر پیشنهاد hash اختصاصی دارد؛ تلاش برای دستکاری payload منجر به رد درخواست می‌شود.
- تمام اقدامات در جدول AuditEvent با سطح ریسک ثبت می‌شوند.
- توکن و مقادیر حساس در خروجی ابزارها به‌صورت خودکار redact می‌شوند.
