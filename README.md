## 🎯 چرا Liara SRE Agent؟

توسعه‌دهندگان در زمان کار با بسترهای ابری معمولاً با دغدغه‌های زیر مواجه می‌شوند:
1. **سردرگمی در انتخاب منابع و پلن مناسب**: تخصیص منابع کمتر از نیاز منجر به کرش (OOMKilled) و تخصیص بیشتر موجب هزینه‌های اضافی می‌شود.
2. **کندی در ریشه‌یابی خطاها (RCA)**: هنگام وقوع خطای ۵۰۰ یا کرش لوپ، بررسی دستی ده‌ها خط لاگ و تحلیل متریک‌ها زمان‌بر است.
3. **ریسک خطاهای انسانی در محیط پروداکشن**: دستوراتی مانند تغییر اسکیل یا ری‌سایز دیسک نیاز به تاییدیه‌های شفاف و بررسی اثرات جانبی دارند.

**Liara SRE Agent** به عنوان یک مهندس SRE اختصاصی در کنار شما قرار می‌گیرد تا این چالش‌ها را به طور کامل حل کند.

## 🌟 قابلیت‌های کلیدی

### ۱️⃣ راه‌اندازی اولیه و اولین دیپلوی هوشمند (Initial Setup & Smart Deploy)
- 🔍 **تحلیل خودکار سورس‌کد**: شناسایی دقیق زبان، فریم‌ورک (FastAPI, Django, Next.js, Express, Laravel و...)، پورت وب‌سرور و فایل‌های وابسته.
- 💡 **پیشنهاد بهینه‌ترین پلن**: تخمین دقیق پردازنده و رم مورد نیاز و پیشنهاد بهترین پلن لیارا (`micro` تا `xxlarge`).
- 📦 **بسته‌بندی خودکار و ایمن**: ایجاد پکیج `.tar.gz` با حذف پوشه‌های اضافه (`.git`, `node_modules`, `venv`).
- 🌐 **تایید نهایی و استقرار**: ایجاد پروژه، تنظیم متغیرهای محیطی، آپلود سورس، ثبت ریلیز و ارائه آدرس زنده دامنه.

### ۲️⃣ مدیریت زیرساخت و عملیات پروداکشن (Infrastructure & Operations)
- ⚡ **مدیریت کامل از طریق API**: دستورات ری‌استارت، روشن/خاموش کردن (Scale on/off) و تغییر پلن (Resize).
- 🔄 **مدیریت انتشار و دیپلوی مجدد**: ارسال سریع آپدیت‌ها و نسخه‌های جدید با بررسی تغییرات.
- 🛡️ **قابلیت Rollback**: بازگشت سریع به نسخه‌های پایدار قبلی با یک دستور.

### ۳️⃣ پایش و مانیتورینگ زنده (Live Monitoring & Proactive Alerts)
- 📈 **داشبورد زنده ترمینال**: نمایش بصری و مداوم مصرف CPU و Memory و وضعیت سلامت کانتینرها.
- 🔔 **سیستم هشدار زودهنگام**: شناسایی خودکار آستانه‌های بحرانی (مانند مصرف حافظه بالای ۸۵٪) قبل از توقف سرویس.

### ۴️⃣ عیب‌یابی هوشمند و تحلیل ریشه‌ای (AI Troubleshooting & RCA)
- 🧠 **تحلیل با مدل زبانی GPT-4o**: جمع‌آوری کانتکست چندگانه (لاگ‌های خطا، رویدادهای سیستمی، کانفیگ، وضعیت کانتینر) و دسته‌بندی علمی خطا.
- 📊 **فرضیات دارای اولویت**: ارائه لیست علل محتمل به همراه درصد احتمال وقوع، اثر بر سیستم و راهکار حل مشکل.
- 🛠️ **اصلاح خودکار با مجوز (Auto-Remediation)**: امکان اعمال مستقیم راهکارهایی مثل ارتقای رم، ری‌استارت یا تغییر پورت پس از تایید کاربر.
- 🔄 **چرخه راستی‌آزمایی (Verification Loop)**: اطمینان از رفع قطعی مشکل پس از اعمال راهکار.

## 🚀 نصب و راه‌اندازی سریع

### ۱. پیش‌نیازها
- پایتون نسخه ۳.۱۱ یا بالاتر
- کلید API لیارا (از منوی حساب کاربری در کنسول لیارا)

### ۲. کلون و ایجاد محیط مجازی
```bash
git clone https://github.com/your-username/liara-challenge.git
cd liara-challenge

# ساخت محیط مجازی و نصب وابستگی‌ها
uv venv
uv pip install -e ".[dev]"

# یا با روش استاندارد پایتون:
python -m venv .venv
source .venv/bin/activate  # در ویندوز: .venv\Scripts\activate
pip install -e .
```

### ۳. تنظیم توکن‌ها
```bash
# تنظیم توکن لیارا
liara-agent config set-token

# تنظیم کلید OpenAI جهت فعال‌سازی بخش هوش مصنوعی (اختیاری اما توصیه شده)
liara-agent config set-openai-key

# بررسی وضعیت اتصال
liara-agent config test
```

## 📖 راهنمای دستورات CLI

### ۱. تحلیل پروژه و اولین استقرار (`init`)
به دایرکتوری سورس پروژه خود بروید و دستور زیر را اجرا کنید:
```bash
liara-agent init
```
*ایجنت زبان پروژه را شناسایی کرده، پلن بهینه را پیشنهاد می‌دهد، پورت و متغیرها را جویا شده و پس از اخذ تاییدیه، پروژه را مستقر می‌کند.*

### ۲. دیپلوی نسخه جدید (`deploy`)
```bash
liara-agent deploy --project my-app
```

### ۳. پایش و مانیتورینگ زنده (`monitor`)
مشاهده شاخص‌های مصرف لحظه‌ای:
```bash
liara-agent monitor my-app
```
پایش مداوم و زنده با رفرش هر ۱۰ ثانیه:
```bash
liara-agent monitor my-app --live
```

### ۴. عیب‌یابی هوشمند و رفع خودکار (`debug`)
هنگامی که سرویس دچار ارور یا افت عملکرد شده است:
```bash
liara-agent debug my-app
```
اجرای عیب‌یابی با تایید برای اصلاح خودکار:
```bash
liara-agent debug my-app --auto-fix
```

### ۵. مدیریت سرویس‌ها (`service`)
```bash
# مشاهده وضعیت تمام پروژه‌ها
liara-agent service list

# مشاهده جزئیات یک پروژه
liara-agent service info my-app

# راه‌اندازی مجدد سرویس
liara-agent service restart my-app

# خاموش یا روشن کردن سرویس
liara-agent service scale my-app 0  # خاموش
liara-agent service scale my-app 1  # روشن

# تغییر پلن پروژه
liara-agent service resize my-app small
```

### ۶. مشاهده و فیلتر لاگ‌ها (`logs`)
```bash
# دریافت لاگ‌های ۳۰ دقیقه گذشته
liara-agent logs my-app --since 30

# فیلتر لاگ‌ها بر اساس کلمه کلیدی
liara-agent logs my-app --grep "error"

# استریم لحظه‌ای لاگ‌ها (Live Tail)
liara-agent logs my-app --follow
```

## 🔒 امنیت و دروازه تایید انسانی (Human-in-the-Loop)

هیچ عملیات حساسی بدون اطلاع و تایید صریح شما اجرا نخواهد شد:
- **عملیات کم‌ریسک (سبز)**: خواندن لاگ و مشاهده وضعیت ← اجرای خودکار
- **عملیات متوسط (زرد)**: ری‌استارت، دیپلوی، تغییر متغیرها ← نیاز به تایید `[Y/n]`
- **عملیات پرریسک (قرمز)**: تغییر پلن، اسکیل خاموش/روشن ← نیاز به تایید محتاطانه `[yes/NO]`
- **عملیات بحرانی (قرمز پررنگ)**: حذف پروژه ← الزام به تایپ دستی کلمه `"CONFIRM"`

تمامی عملیات به صورت تغییرناپذیر در فایل لاگ ممیزی (`audit.log`) ذخیره می‌شوند.

## 🎥 سناریوهای ویدیوی دمو (۵ دقیقه‌ای)

1. **سناریوی اول (۹۰ ثانیه)**: اجرای `liara-agent init` در یک پروژه نمونه، تحلیل خودکار، پیشنهاد پلن، تایید انسانی، استریم پیشرفت و دریافت URL نهایی.
2. **سناریوی دوم (۱۲۰ ثانیه)**: شبیه‌سازی کرش OOM / خطای سرور، اجرای `liara-agent debug`، نمایش تحلیل ریشه‌ای هوش مصنوعی (RCA)، تایید راهکار اصلاحی، اجرای تغییر پلن و تایید بازگشت سلامت سرویس.
3. **سناریوی سوم (۴۵ ثانیه)**: مدیریت دیپلوی مجدد با `liara-agent deploy` و عملیات `scale` / `restart`.
4. **سناریوی چهارم (۴۵ ثانیه)**: اجرای `liara-agent monitor --live` و نمایش داشبورد زنده مصرف CPU/RAM.
